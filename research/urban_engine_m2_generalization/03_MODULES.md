# Reusable modules implemented in M2

| Module | What it does | Inputs, outputs | Tests |
|---|---|---|---|
| `tools/urban_intake.py` | Reads DXF through the K2 kernel: segments, arcs, circles, ellipses with WCS geometry and instance-unique ids; texts placed by recursive decomposition; attributes; inserts; hatches. Reads PDF pages (vector segments and words, or RASTER_ONLY). DWG is refused. | path, then dict | `test_cad_geometry_fixtures` (7) |
| `engine/source/drawing_model.py` | Normalisation (Ø, Arabic digits, NFKC), sheet frames, title roles and storeys (EN / AR lexicons; a title opening with "schedule" is a schedule), mark families, closed rectangles, unit inference | intake, then model | components |
| `engine/source/schedule_reader.py` | Attribute-row schedules (mark field found by content, size words W / H / D, bar pairs, storey prefixes) and drawn text tables (header words fix columns); unit inference; conflicts for duplicate marks with different sizes | attributes or texts, then rows, library | components (4) |
| `engine/source/member_detection.py` | Footings (template outlines at schedule sizes, states CONFIRMED / SIZE_MISMATCH / COMBINED_OUTLINE / TYPE_NOT_IN_SCHEDULE / NO_OUTLINE / TYPE_BY_SIZE_MATCH, nested and duplicate rule); column occurrences (never a footing outline); beam edge layers by evidence; bands; split at supports; mark binding; collinear inheritance; quantities under total-depth and below-slab readings | sheet entities, schedule library, then members | synthetic |
| `engine/source/cad_heal.py` | Merges collinear pieces and duplicates within 3 mm. Extends dangling face ends to the first line within 5 mm, or within 10% of the narrowest member width, then reported as HEAL_EXTEND_WIDE | segments, then segments and log | components (2) |
| `engine/source/slab_engine.py` | Topology faces classified by evidence (BEAM / COLUMN / OPENING / PANEL / DETAIL / OPEN_BOUNDARY); thickness printed > sheet uniform > convention; unenclosed band sides reported; opening labels written as English keywords only | edges, bands, columns, then faces | synthetic, ownership |
| `engine/source/bar_shapes.py` | Straight, hooked and closed-link developed lengths from the bar diameter and a named code table (ACI 318-19, PROVISIONAL_CODE_METHOD); mass d²/162 | dims, then developed m | components (11) |
| `engine/source/generic_route.py` | `detect()` per sheet role; `items_from()` gives V / P / U items, a rebar register (MEASURED / PROVISIONAL_MODEL / MISSING_DATA / EXPLICIT_NONE / OUTSIDE_SCOPE) and the coverage-risk register; `scope_scan()` for families it cannot quantify; `merge_conventions()` with profile and overrides | intake, conventions, then items, register, risk | all |
| `engine/source/room_slice.py` | Architectural rooms from wall line work plus door thresholds: floor m², one-sided perimeter, skirting less door widths, wet-room waterproofing with the doorway piece and 0.15 m upturn; wet-room skirting unresolved until the tile height is known (UP-CER-001..004, UP-WP-001..003) | entities, then rooms | `test_room_slice` (3) |
| `engine/source/stair_generic.py` | A straight flight from a counted riser number; marble by UP-STAIR-002..009; concrete an exposure range while the waist is unknown; scenarios side by side | rise, n, going, then flight | `test_stair_generic` (4) |
| `tools/urban_boq_m2.py` | One-command BOQ: routes A / B / C delegated to the frozen M1 CLI; route G; BOQ section C NOT DETECTED; COVERAGE_RISK, REBAR_COMPLETENESS, overlays; Excel sheets; opt-in intake cache | drawings, then the output folder | route G, cache (2) |
| `tools/m2_overlay.py` | Source-coordinate overlays: bands by binding state, slab faces by class and thickness basis, footings by state, columns, risk markers; engine marks only | detection, then SVG / HTML | route G hygiene |
| `tools/synthetic_villa.py` | Seeded villa designs written to DXF, with truth from the design (quantities and component positions); variants (units, languages, layers, tag sets, curved beam, untagged span, width conflict, missing type, opening); `--defects`, `defects="hard"` | seed, then DXF and truth | generator independence |
| `tools/m2_evaluate.py` | Per-drawing and summary metrics: per-family error, detection precision and recall, slab silent loss, range sanity, timing | seeds, then JSON | — |
| `research/urban_engine_m2_generalization/build_m2_reports.py` | The Alsenan route G run beside the frozen replay; the 89 components; the ground-slab audit; benchmark positions; stair scenarios; metrics; hygiene and firewall checks | — | `test_m2_reports` |
| `engine/profiles/URBAN_M2_GENERIC_CONVENTIONS_V1.json` | 20 named, reversible conventions (choices, exposure ranges, covers, anchorage, laps, mesh directions) | — | — |
