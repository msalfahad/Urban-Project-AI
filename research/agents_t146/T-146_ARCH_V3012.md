## 1. The physical question (ERS s.2.1)

A suspended RC floor is plates between the faces of the members that carry them, and the members at full depth (C1).
Every piece of each slab plan has ONE owner: a panel -> CONC.SLAB; a band, a ring, a junction square, a strip or box
outside the outer beams -> the beam lane (measured, CONFLICT range or HELD); a drafting mark -> no line. The candidate
(V3.0.11) breaks this in both directions: it bills 13 faces that are not slab as slab (+0.639 m3), it leaves CB5 span 2
in no beam line (its band is one of those 13 faces), bills the GF void ring as route bands that miss 0.292 m2 of the
drawn ring, and releases five D-02 / D-27 width-conflict spans at the schedule width. The slab and beam ledgers must
therefore enter the candidate together: a face may leave the slab line only for a run of the same package.

## 2. What the module does (`engine/source/arch_v3012.py`, new; `DEFAULT_GUARD_CLASS = "GUARD_HOST"`)

- **BEAM_LEDGER**: every candidate STR.CONC.BEAM line on GF / 1F / 2F is accounted for or the run is refused:
  KEPT (the line already carries its run: one band, one run, the same figure within 0.0001 m3, i.e. two 4-decimal
  roundings of one measure; or the same held range; or a held run the candidate already holds with no value) ->
  byte-identical; SUPERSEDED (NOT_APPLICABLE_WITH_EVIDENCE, figure kept as information, named by every run it feeds;
  a band split into two spans feeds two runs) -> one new line per replacing run: CALCULATED -> SOURCE_DERIVED
  (VERIFIED where the record names the Checker run), CONFLICT -> BOUNDED_EXPOSURE of its two readings (HELD), HELD

  from its base less its named adjustments; a run above 50 m3 is a unit slip; declared totals asserted.
- **SLAB_FACE_HOME**: each non-slab face line retired with its home (a run of THIS package's beam ledger, kept or
  added, or NOT_CONCRETE with drawing evidence); a face to the beam lane without the beam piece is refused; the slab
  line left on each floor must equal T-234's hand figure within 0.0005 m3.
