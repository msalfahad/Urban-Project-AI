## Determinism

- `urban_project_run.py check` rebuilds a frozen run in memory and compares every output byte for byte
  (`test_m7_project_run.py`).
- The ST7757 records rebuild byte for byte from the working tree (`test_m7_package.py`, live, with the private
  drawings): BY_FAMILY, FINDINGS_DELTA, RELEASE_REGISTER, RELEASE_TOTALS, SUMMARY.
- `build_package.py --check` rebuilds every CSV register from the committed records.
- The workbook is regenerated by the same builder and recalculated with LibreOffice (0 formula errors, 43 formulas);
  the PDF carries no creation date and rebuilds byte-identical (`test_m7_package.py`). Neither is in git (like
  every earlier package's PDFs and workbooks): both are rebuilt from the committed records.
- The held-out summary records the sha256 of every held-out record file (`test_m7_package.py` re-hashes them).
