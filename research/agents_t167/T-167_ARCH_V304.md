## 2. Method (generic, any villa) and what was built

Physical test, not text search: re-run the same candidate with the non-usable values removed; a line whose quantity state
(evidence state, value, range) moves rests on them. Removing a value is not replacing it: route G then holds the line on
its own generic range or does not emit it.
