# S8.6 post-freeze comparison

Frozen package verified before and after. Classes: DOUBLE_COUNT 3, GEOMETRY 7, MISSED_OBJECT 10, NO_DIFFERENCE 6, SUPPORT_IDENTITY 43.

- V3b lintel concrete 4.749 m3 ({'GF': 2.726, '1F': 1.493, '2F': 0.53}); S8.6 releases 0.745261681 m3 and holds 4.231716541 m3 as sensitivity.
- V3b counts 0.212 m3 twice (four R5 door + glazed-door pairs).
- V3b lintel bars 582.478 kg (hooks from ACI tables, a generic rule the project does not state); S8.6 releases 96.427279858 kg, sensitivity 522.09111712 kg.
- Main cause: V3b gives every opening a lintel; S8.6 blocks the openings with an S1 beam band over them until a head level is printed.
