## 4. General rule (proposed, any villa; provenance: standard s.2-3 + UP-OPEN-CONSIST-001 / UP-OPEN-CENSUS-001 proposals; new)

UP-OPEN-GEOM-001 v1.0.0 (proposed, a new rule file; never an edit of an existing one): where no sheet prints an opening's
head or sill, the drawn geometry of a VECTOR source of the set (DXF, DWG, DWF / PDF vector plot) establishes it as
DRAWING-CONFIRMED (geometry) only when (1) the datum is a printed level of the same view, (2) the opening is bound to the
plan by along-facade position with every spacing and the drawn width agreeing with the plan within 0.02 m, (3) the value
is re-datumed to the FFL of the floor it sits on, and (4) the vector source is the current issue or every edge agrees
with the current issue within its resolution; a raster is never scaled; a printed value, when issued, governs (the
set's note "dimensions not to scale"); an outline whose width does not match the plan (shutters, frames) gives candidates
only (HELD); a section cut gives the head at the cut only. Before any value is declared "not drawn", every file of the
project folder is identified by its format signature, not its name or size.
