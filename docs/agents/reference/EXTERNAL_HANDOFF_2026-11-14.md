# Al Senan BOQ accuracy upgrade

Implementation brief for Claude Code • Urban Project AI • 14 Nov 2026

## Objective

Build one reliable drawing-to-BOQ path for a villa. Increase the number of correctly measured physical items, make omissions visible, and keep each released quantity traceable to the governing geometry, detail, schedule and project rule. Use Al Senan as a regression, and prove generalization on a different villa whose BOQ stays sealed until the run freezes. Start from the existing project board (T-772, T-773, T-774, T-775) and confirm the latest branch before editing. Keep the established structural Route G and working architectural calculations.

The audit reviewed `951682c57f4c0f8444144a6d0ac20fcc12d92b99` on `claude/access-permissions-setup-ii24ws`, with `agents/control` at `012c3d80e90b1b92a5bbac8247c133eabc28efe0`. The frozen Al Senan comparison used `2c6a2822cf7b18ae0992bd2d190b717d5cf94b5c`. Check changes since those commits. The run on the current audit checkout with V3.0.79 and drawings plus structural configuration exited early with `ARCH_TAKEOFF_V3.0.16 needs --v3016-inputs (the project identity and revision set)`. Research wrappers replay the staged history with project data. T-314 validates and reads 126 pinned T-756 exterior faces and maps them to 18 render lines. The committed V3.0.79 index has 5,275 records, including 2,813 held. Convert the generalizable part of that operation into drawing-to-face production logic, and keep staged replay separately identifiable. A separate read of T-770 V3.0.81 at `6fc6bbf5e1a1156e5b34993ac1bf30d668f861fb` found that `engine/source/arch_v3081.py` applies committed figures to matching line IDs, with matching unit, element ID and before state. It already labels non-measured filled points provisional. Preserve these reconciliation guards and connect them to scoped source facts. The audit did not run V3.0.81.

- Use P7757 architectural DXF, architectural PDF sheets 01–12 in two files, ST7757 DXF and equivalent DWG, ST7757 PDF (16 pages), and the sanitary PDF (3 pages), plus the applicable versioned Urban rules. Deduplicate the equivalent structural models by scope and revision.

### 1. Manifest and source-to-fact evidence

Inspect `tools/urban_boq_m9.py` (`cmd_arch`, parser, V3 inputs), `tools/urban_project_run.py` (manifest/run/freeze/compare), `tools/arch_intake.py`, `engine/source/arch_measure.py`, `wall_height.py`, `opening_height_pdf.py`, `project_rules.py`, `raster_evidence.py`, `calibration_v2.py`, `drawing_model.py`, `frame.py` and `benchmark_firewall.py`. Start by tracing which PDF extractors and evidence objects are already reachable. Connect usable modules to production intake. Preserve the existing output schema for current callers and add manifest generations only where needed.

- Separate source representation from engineering authority. Use CAD for coordinates and connectivity, a signed/revision-matched plan/section/detail/schedule/spec for design facts, and review for ambiguous extracts. Explicit scoped project design governs. An owner default yields an adopted scenario with provenance. A ratio remains an estimate.
- Produce typed facts for storeys, FFL/SFL, soffit, finish ceiling, floor build-up, wet ceiling/tile limits, sill/head/mark, facade material, membrane extents, wall-type details, concrete thickness and scope. Each finding carries document hash, page/region or CAD handle path, view-to-model transform, label and unit, engineering role, floor/zone/member scope, derivation, review decision and supersession. Key the binding by section/level lineage and element identity, with nearby text only as a proposal.
- Classify PDF pages as text/vector/raster or mixed. P7757 architectural PDFs have 12/12 image-only pages with zero native text. Run local OCR for Arabic/English on cropped title, dimension, schedule and note regions at multiple resolutions. Use vector/native text where available, crop and retain the evidence where it is outlined. Handle Arabic digit normalization, mixed right-to-left text, decimal points, unit conversion, 'U/S of slab' vs FFL, mirrored/split tables and contradictory views. Record disagreements. An OCR confidence threshold by itself does not approve an engineering fact.
- Calibrate each relevant viewport with multiple independent anchors, with at least two held out for verification where available. Report fit and holdout residuals, orientation, axis scales, duplicates and rejected anchors. CAD `$INSUNITS`, shown `DIMLFAC` and measured geometry serve different roles; avoid multiplying CAD coordinates again from a displayed dimension's style. Keep graphic-scale, printed floor-area table and net finish areas separate.
- Allow document-level, scoped human evidence approval. Provide a deliberate fallback to a confirmed PDF crop when CAD geometry is missing or in conflict. Prompt for the specific unresolved fact and expose it in the workbook. Avoid one global room-height patch. On Al Senan keep GF main, 1F main and GF annex distinct (board plaster decisions 4.34 m, 4.04 m and 3.84 m respectively, conditional on the documented basis). Compute plaster, paint and tile heights independently. Never use a floor-to-floor height as a finished wall height without its required components.

**Acceptance.** On P7757 identify the 12 image-only pages and bind evidence with page, crop, measured units and floor/zone. On ST7757 PDF p8 item 18 identify 160 mm as the standard roof slab, and on p13 identify the 100 mm layer under the isolated footing. Failed or conflicting OCR remains a review task. Show all recovered first-floor plaster obligations and the source of every height, retaining a gross/bounded output if opening deductions remain unestablished. The audit 4.04 m probe changed 11 blocked plaster lines into 10 bounded lines and one numeric net tagged SOURCE_DERIVED/MACHINE_ONLY. Carry owner-adopted lineage through stacking even when the existing evidence enum is SOURCE_DERIVED. Gross before openings was 742.029508 m², while the raw missing-evidence count stayed 140. On the actual p8 crop local bilingual OCR read 16 cm at 2× and 6 cm at 4×. In synthetic tests a source revision mismatch, unsupported transform and unsupported geometry block the specific affected quantity. Missing reference books must not stop the run.

### 2. Geometry graph and finish completeness

Inspect `engine/source/cad/kernel.py`, `kernel_ezdxf.py`, `room_topology.py`, `arch_rooms.py:zone_partition`, `arch_floor.py:split_face`, `arch_measure.py`, `opening_authority.py`, `wall_contact_path.py`, `arch_run_audit.py` (under `tools/` where present), and staged T-240/T-427/threshold reconciliation. Inspect existing fallback code before replacing it.

- Normalize per view and keep occurrence identity through nested blocks, OCS/WCS, nonuniform scale, mirror, arcs, MINSERT, viewport clipping and xrefs where encountered. A whole drawing may include elevations, duplicate views and void symbols alongside the plans. Add a per-view raw/normalized/consumed/rejected census with lost entity reasons, backed by existing fixtures. Use native independent queries when an available verifier materially improves a fixture. P7757 and ST7757 had no xrefs in this audit, so test xrefs synthetically and on a real future project before claiming an Al Senan effect.
- Build a non-overlapping physical cell partition with attributed edges and holes. Handle snap tolerance as explicit in normalized physical units and test it across accepted variants. Use `polygonize_full` to record dangles, cuts and invalid rings and use coverage validation and geometric symmetric difference to detect overlaps or an unexplained loss of area. Preserve semantic zones (open pantry, dining, living) independently of physical floor ownership, and label intentional holes before comparison. Track full gross/net and allocated/residual area by storey and material, including threshold ownership.
- Build an obligation census independently of emitted BOQ rows. For each physical floor cell decide required porcelain/wet tile/marble/other or inapplicable with evidence, and similarly for ceiling, wall partitions, side faces, thresholds and upturn edges. Join expected obligations to output using revision/group, storey, physical ID, trade, surface and finish. Require every obligation to have a measured, bounded/adopted, held, or evidenced N/A state. Show expected and emitted population/geometry coverage. Semantic zones may share a cell, but coverage allocates the geometric piece once.
- For assemblies use plan mark and unique physical occurrence, plus schedule or elevation-linked evidence for width/height and sill. Convert curved area only using the governing developed/straight rule; aggregate assembly count and m² independently. Measure walls as segments plus two separately owned finish surfaces, thresholds on their owner material, and stair treads, risers and landings as distinct properties.
- Build takeoff surfaces from the same wall and slab objects, so changes flow across blockwork, exterior render, plaster, paint, tiles, ceilings, trim and membranes. Exterior gross wall area, exterior net finish, opening reveals, returns, and edges need their own fields and units. Wet-floor area, membrane vertical net, coverage/procurement with laps and upturn run in lm need their own fields. Apply owner wet-area rules to eligible rooms, including pantry and service rooms, and treat no paint/skirting on full-height porcelain faces as an explicit rule application. Respect approved doorway-upturn treatment and threshold material.

**Al Senan regression seeds, never production constants.**

- 1F-RFFE7AF dressing: 2.970 m² (1.65 × 1.80) measured in ARCH.SPACE but absent from published finish. Freelancer first-floor bedroom D23 contains 3.80 × 4.30 + 1.00 × 0.15 + 1.65 × 1.80 = 19.46 m². The group parent must reconcile whether the dressing is published separately or grouped. Ensure it is counted once.
- GF dining: 4.885 m² "UNALLOCATED_MERGED" inside the drawing-based partition. 0.760 m² in OP-003 may belong to the dining finish. That opening also contains 0.240 m² exterior, 0.040 solid, 0.600 pantry and 0.604 held curb in the reviewed split. 9.101 m² garden stays a separate exterior/held scope unless project evidence changes its treatment.
- GF stair room: 6.1275 m² measured footprint with unresolved finish. 2F: 2.20 m² porcelain candidate (2.50 − 0.30 lift); 4.875 m² arrival marble on a separate line and ownership distinct from stair flights; allow the 0.30 m² lift threshold as a separate physical scope. Against the QS 7.70 m² row the reported residual is 0.325 m² when that threshold is included. 1F living: frozen 44.869 m², freelancer 38.96 m², subsequent drawing-led candidate 33.411 m² after separation. Compare masks and rule explicitly before promotion.
- Match 17 wet rooms at 72.1207 vs 72.01 m² on the checked basis, including the 9.6300 m² kitchen classified as porcelain in the baseline. Preserve the strong geometry while correcting the wet class consistently. Review the separately classified open pantry once.
- Ground/1F/2F observed gross plates 284.1465/209.8017/55.0800 m² vs printed 319.99/208.20/55.08. Do not force scale to match the administrative area table. Explain the basis by floor, especially GF.

**Acceptance.** Machine-readable coverage includes every obligation and measures unclassified areas explicitly. Drawing overlays locate every held/overlap/residual and every detached finish. Synthetic variations for a mirrored nested insert, offset/arc walls, garden, threshold, detached dressing, void, duplicate insert and open pantry preserve signed area accounting. Fixes derive from source and apply to the second villa without its quantities entering rules. Adopt 0.005 m² as a proposed closure tolerance on exact synthetic partitions and review real drawing tolerances by input precision.

### 3. Member census, net volumes and roof planes

Inspect `engine/source/concrete_ledger_v3.py`, `route_g_scope_v1.py`, `ground_system_spans_v2.py`, `ground_slab_recovery.py`, `slab_engine.py`, `pool_qto.py`, `stair_steps_concrete.py`, `scope_crosswalk_v1.py` and the corresponding V3 modules. Use plan marks plus scheduled types, explicit default when applicable, and a design inventory keyed to occurrence and storey. Reconcile expected instance to quantity once.

- Track isolated/strip footings, ground beams, straps, ground slab/panels, columns, suspended slab, beams, stairs, pool, lift pit and external/boundary members. Use cross-sheet joins for repeated instances. Separate blinding, screed, ground slab and roof slab in the taxonomy.
- Show gross contributions and deduplicate physical intersections at footing/strap, beam/slab, beam/beam, column/slab, and wall/slab junctions by approved ownership. Start with plan footprints plus vertical extents (2.5D); compare an independent geometric reconstruction for a small set of junctions. Escalate true slope or complex solids to source sections or IFC when it exists.
- Tie thickness, plan extent and what bears on each layer to independently scoped facts. QS concrete workbook E15 = 15.00 × 31.37 × 0.10 = 47.055 m³; frozen engine 22.155 m³ under footing/beam scope. Structural p13 shows local 100 mm plain concrete under isolated footings and representative ground beam details, p7/p14 contain separate scopes to enumerate, and p8 item 18 is a standard 160 mm roof slab. Determine each extent from the applicable sections/plan. An unscoped full-plot blinding scenario may be priced if owner accepts, with drawing-based localized work shown independently and overlap checked.
- For roofs enumerate each waterproofable plane by roof level and physical ID. Track access stairs, outlets, parapet/upstands, domes/slope, exposed slabs, excluded areas, horizontal layer and membrane on vertical surfaces. Separate net installed from purchase allowances by laps and rolls.
- Preserve separate direct outputs for estimated steel and measured steel if enabled later. Original workbook H17:H23 and H25 are hard-coded; derived kg/m³ there cannot validate measured tonnage. Resume BBS only with mark counts, bar shapes, diameter, laps/couplers/hooks, supports and schedule scope. Use regional approved detailing where the drawings delegate it.

**Acceptance.** Element-instance census reconciles direct and deduced representatives, with unallocated and ambiguous populations explicit. Junction test proves the total union volume and per-member deductions; a missed-pool or boundary-wall regression fails even if aggregate m³ stays within target. Roof ledger ties independently reviewed extents to emitted quantities by plane and explains missing items. Baseline RC 319.800 versus QS 352.436 m³ is a historical observation; re-score like-for-like before claiming a reduction.

### 4. Benchmark quality and release

Use `tools/urban_project_run.py`, `engine/source/scope_crosswalk_v1.py`, existing scoreboard release code and T-775. Output a blind workbook, physical coverage report, evidence overlays, sealed-input manifest, and a separate comparison workbook. Include owner assumptions and scope RFIs, units and source references. Keep both old and new hashes for comparison. Create one canonical contract scope crosswalk, with unit, significant dimensions, basis (gross/net/installed/purchase), reference formula lineage, occurrence keys and disposition. Compare by floor, item group, physical element and unit, and require clerical problems to fail metrics.

- Fixed benchmark checks: original aluminium cover shows 12 m² for doors; detail shows five exterior door assemblies. Window references include 29 assemblies and 116.90 m², whereas the baseline detected 27 window candidates. Join by plan mark and storey issue, then compute count and area scores independently. Link plywood/edge items in lm separately from areas as appropriate. Do not compare wet membrane upturn area to perimeter length. Original interior paint net 1,191.1275 m² and board comparison 1,209.4 m² use different comparison populations.
- Compare signed delta and WAPE (sum absolute errors ÷ sum reviewed comparator quantities) per compatible family. Publish number and area/volume coverage, accepted exact/field measurement, adopted assumptions, bounded coverage, held, and evidenced N/A with distinct denominators. Negative/positive storey deltas cannot cancel inside the error score. Missing scope is an omission with a reason, never silently treated as zero or as a source-verified number.
- Demonstrate current and new build on identical input tags. A starting owner-review gate for held-out measured families is median matched-room area error ≤ max(0.10 m², 0.5%) and per-family WAPE ≤ 3% where scope is matched and quantity coverage ≥ 98%. These are proposed acceptance targets, not Al Senan outcomes. In addition, require 100% accounting of obligations, including holds, and zero wrong-unit comparisons, unsupported releases, known whole-layer omissions or benchmark access before freeze. Adopt targets per trade after the blind holdout and retain disagreements where the drawings and freelancer have different scope.
- Prove one command from drawings and approved rules in a fresh workspace. Move old ledgers and filenames away, randomize file order and names, prepare malformed and mixed-revision negative controls, verify stable geometric identity and reopen the comparison only against the same freeze.

## Tool decisions

| Candidate | Concrete use | Decision |
|---|---|---|
| ezdxf + existing CAD kernel | Deterministic source, handle/occurrence paths and stable geometry | Keep. Add differential fixtures for clipping, dimstyle, arcs, mirroring, nested hatches and xrefs. ezdxf virtual entities alone omit some cases. |
| Shapely / GEOS | `polygonize_full`, fixed-precision operations and coverage diagnostics | Use with explicit precision in normalized coordinates. Validate retained area, intended gaps and overlap against independent controls. |
| PyMuPDF or pypdfium2 + Tesseract `ara+eng` | Render per region and propose typed text evidence | Keep processing local. Record crop, OCR version, language, confidence and reviewer decision. Use an independent render when source display is disputed. |
| OpenCV geometric alignment | Constrain model/sheet registration from anchors and measure residual | Use for initial crop alignment and QA. Require labeled independent dimension checks before binding. |
| AutoCAD MCPs (U-C4N, beiming183-cloud, C48H74) | Independent read-only live-native validation or spot-check of DXF mode | Optional controlled pilot on the existing synthetic CAD fixture bench. No private drawing transfer to an external service. Compare exact operator queries, version/platform, represented XREF/clipping/bulges and repeatability. |
| Autodesk RealDWG / ODA | Native DWG access/conversion where client feeds need it | Use only if CI/host licensing and the fixture results warrant it. Existing local DXF path works for these samples. |
| IfcOpenShell | Model quantity and geometry audit for actual IFC sources | Add a separate source adapter when IFC is supplied. Do not generate a fake IFC proxy from noisy linework merely to measure the current villa. |

Extend existing `.claude/skills/urban-cad-audit`, `urban-floorplan-vision-review`, `urban-boq-proof`, `urban-freeze-integrity`, `urban-mcp-benchmark` and `urban-rule-reconciliation` as required. Use `research/urban_m9_p2b5/MCP_SKILLS_AUDIT.md` and its fixture suite as the gate. Prefer one evidence workflow addition across those existing skills over a new skill that only provides prompts.
