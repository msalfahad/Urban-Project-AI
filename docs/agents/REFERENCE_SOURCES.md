## How agents may use them (owner rule: no assumptions)

A book is evidence, not an Urban rule. A number or method found in a book may be used to (a) check a result, (b) explain a
difference, (c) write an owner question with the book page as the source. It becomes a rule for the engine only when the
owner confirms it in OWNER_QUESTIONS.md. Where a book disagrees with an owner answer, the owner answer governs and the
difference is recorded. Refer to a book only by its Drive folder and title; never copy its pages into the repository.
