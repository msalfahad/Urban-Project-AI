## How to change a rule

1. Find the rule above. Note its rule set (knowledge registry or rule store) and the code and tests listed.
2. Knowledge registry (methods V2.3 and later): add `knowledge/URBAN_ENGINEERING_KNOWLEDGE_<next>.json` built from 1.4.0 (earlier versions were made by `tools/kb_build_*.py`), register it in `VERSIONS` in `engine/source/knowledge.py`, and bind it to a new method version. Existing versions are read by frozen methods and stay byte-identical.
3. Rule store (V1-V2.2, frozen): add `rules/owner_decisions/URBAN_RULES_<next>.json` as an overlay, add it to `VERSIONS` in `engine/source/rule_store.py`, then `python3 -I tools/m9_rules_manifest.py build` and `check`.
4. Run the tests listed for that rule, then the read-only freeze check (expected: 0 differing).
5. Run `python3 -I tools/codemap.py` so this index shows the new version.
